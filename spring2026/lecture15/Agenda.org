** Network byte order vs host byte order
 + Remember byte order from way earlier in the class?
 + How the bytes of multi-byte data are stored in memory
   + Example: 0x123456789ABCDEFF
   + big-endian
     + lowest address contains the byte corresponding to 0x12
   + little-endian
     + the lowest address contains the byte corresponding to 0xFF
 + "network byte order" is big-endian
   + but not every computer is!
   + x86-64 is always little-endian
 + hton(s/l)
 + ntoh(s/l)

** (Stretch) Select and poll
 Classic ways to handle multiple clients /without/ forking or threading
*** select
 Dates all the way back to Unix and has been around since Linux was born

 You can watch file descriptors and fill a datastructure and rather than block on a read/recv (or write/send) you can just run a loop that checks if anyone is ready and, if they are, Do The Thing.

 It's cute but a little weird. 
*** poll
 This is a little newer and a little fancier. It has less weirdness and is a little more flexible.
*** epoll
 This is the super-efficient modern version of poll.
