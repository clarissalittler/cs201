** Why does Rust exist?
 - We need to do low level programming, systems programming, &c.
 - But as we've seen C's typesystem has about as many holes as the plot of [insert a movie you hate here]
 - You can really shoot yourself in the foot easily with
   - malloc and free errors
   - Buffer size mismatches
   - Casting mismatches
   - Passing pointers incorrectly
   - And general type errors caused by the fact that everything "is a number" and can be used in a conditional
 - Lots of higher-level languages fix all of these /but/ they also end up sacrificing performance with garbage collection and "boxed" types (i.e. heap allocated objects rather than simple types interpretable as bits)
 - Rust tries to split the difference by having the advantages of a good type system but have it still /feel/ like C *and* no garbage collection
 - How do you have no garbage collection? With the magic of a linear (more correctly /affine/) type system!
 - The type system enforces certain conditions of how resources are created and used so it's possible to calculate the point at which it's safe to free allocated memory
