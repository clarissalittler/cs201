** Rust! Why does it exist?
 + C's holes: malloc/free errors, buffer mismatches, wild casts
 + higher-level languages fix these but pay with garbage collection
 + Rust: a real type system, C-like feel, no GC -- via affine types
   (the compiler tracks ownership and inserts the frees)
