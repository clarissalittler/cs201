** What does read return?
 + Positive: this many bytes
 + Zero: end of file
 + -1: an error
 + This is a byte count, not a string length
 + The buffer doesn't have to contain text or a terminating zero
** Why are there two loops?
 + Read until EOF
 + Write until we've sent all the bytes from that read
 + Suppose write only writes three bytes
   + Where should the next write start?
   + How many bytes remain?
 + Interrupted calls and real errors
