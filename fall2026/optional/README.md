# Optional material

These folders are extensions, not numbered lectures in the Fall sequence.

- [IPC](ipc/Agenda.org): pipes, shared memory, and related examples after file I/O.
- [Networking](networking/README.md): select/poll alternatives after sockets.
- [Rust introduction](rust1/Agenda.org) and [Rust data types](rust2/Agenda.org): extra clinics after the core material.
- [C++ reference](reference/text.org): the longer reference previously stored with file I/O.
- [Project workshop](project-workshop/Agenda.org): protected project time and course synthesis, formerly lecture 20.

The scheduled course runs from [lecture1](../lecture1/Agenda.org) through
[lecture20](../lecture20/Agenda.org). Actual extra sessions can be chosen once
the calendar is set.
